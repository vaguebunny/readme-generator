# README Generator

  ![License](https://img.shields.io/badge/license-MIT-blue.svg)

  ## Description
  This is a readme generator that utilizes the CLI. The program asks questions for the client to answer. When complete, a readme file is created.

  ## Installation
  Installation process requires node.js and inquirer packages. Once applied, download this project's files and use your CLI to run node index.js for the generator to begin.
